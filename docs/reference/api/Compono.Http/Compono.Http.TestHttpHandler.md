## TestHttpHandler Class

A reflection\-free [System\.Net\.Http\.HttpMessageHandler](https://learn.microsoft.com/en-us/dotnet/api/system.net.http.httpmessagehandler 'System\.Net\.Http\.HttpMessageHandler') fake for testing code built on
[System\.Net\.Http\.HttpClient](https://learn.microsoft.com/en-us/dotnet/api/system.net.http.httpclient 'System\.Net\.Http\.HttpClient') \- the sanctioned \.NET substitution seam \(ADR\-0051 "Core abstraction"\)\.
Configure responses with `OnGet`/`OnPost`/`OnPut`/`OnPatch`/`OnDelete`
\(exact\-method, [Match&lt;T&gt;](../Compono/Compono.Match_T_.md 'Compono\.Match\`1')\-based path matching\) or `When` \(a whole\-request
predicate\), then build one or more [System\.Net\.Http\.HttpClient](https://learn.microsoft.com/en-us/dotnet/api/system.net.http.httpclient 'System\.Net\.Http\.HttpClient')s over this handler via
[CreateClient\(Uri\)](Compono.Http.TestHttpHandler.CreateClient(System.Uri).md 'Compono\.Http\.TestHttpHandler\.CreateClient\(System\.Uri\)')\.

public sealed class TestHttpHandler : System.Net.Http.HttpMessageHandler

### Remarks

<b>Matching</b>: registrations are evaluated last-registered-first, first match wins (ADR-0051
            "Precedence") - a later registration overrides an earlier, broader one. A request matching no
            registration throws [UnmatchedHttpRequestException](Compono.Http.UnmatchedHttpRequestException.md 'Compono\.Http\.UnmatchedHttpRequestException') rather than a fabricated
            response (ADR-0051 "Unmatched requests: strict by default"); configure an explicit fallback with
            `handler.When(_ => true)` if one is wanted.

<b>Lifetime</b>: this handler is caller-owned. Compono composition (`[Shared]`/
            `CompositionRow`) does not own or dispose it - see ADR-0051 "Lifecycle, disposal,
            concurrency". Every [System\.Net\.Http\.HttpClient](https://learn.microsoft.com/en-us/dotnet/api/system.net.http.httpclient 'System\.Net\.Http\.HttpClient') from [CreateClient\(Uri\)](Compono.Http.TestHttpHandler.CreateClient(System.Uri).md 'Compono\.Http\.TestHttpHandler\.CreateClient\(System\.Uri\)') is constructed with
            `disposeHandler: false`, so disposing a client never disposes this handler, and multiple
            clients may safely share one handler. Disposing this handler invalidates subsequent sends
            through any client still wrapping it.

<b>Concurrency</b>: configure registrations before the system under test runs - configuration
            concurrent with `Compono.Http.TestHttpHandler.SendAsync(System.Net.Http.HttpRequestMessage,System.Threading.CancellationToken)` calls is unsupported/not guaranteed. Concurrent
            `Compono.Http.TestHttpHandler.SendAsync(System.Net.Http.HttpRequestMessage,System.Threading.CancellationToken)` calls themselves are fully supported.
