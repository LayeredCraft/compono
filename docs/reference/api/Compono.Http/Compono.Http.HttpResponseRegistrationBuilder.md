rejects any further `WithX`/`Respond*`/`Throws` call \- the finalized
[HttpResponseRegistration](Compono.Http.HttpResponseRegistration.md 'Compono\.Http\.HttpResponseRegistration') is built from an immutable snapshot of the matcher chain
\(ADR\-0062 D2\), so it can never observe a later mutation attempt even hypothetically\.
