## HttpResponseRegistrationBuilder Class

Returned by [TestHttpHandler](Compono.Http.TestHttpHandler.md 'Compono\.Http\.TestHttpHandler')'s `OnGet`/`OnPost`/\.\.\./`When` methods \-
finishes configuring a matched request's response\. Every method here finalizes and returns the
underlying [HttpResponseRegistration](Compono.Http.HttpResponseRegistration.md 'Compono\.Http\.HttpResponseRegistration') handle \(never [void](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/void 'https://docs\.microsoft\.com/en\-us/dotnet/csharp/language\-reference/keywords/void')\), so the
caller can capture it for verification \(`registration.Verify().Once()`\)\.
