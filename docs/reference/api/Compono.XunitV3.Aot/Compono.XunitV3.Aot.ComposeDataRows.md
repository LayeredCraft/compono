## ComposeDataRows Class

Shared runtime support for `[ComposeData]` theory rows, compiled into both
`Compono.XunitV3` and `Compono.XunitV3.Aot`\. It normalizes row shapes, extracts and
validates `TConfig` values, validates leading positional row values, merges row/attribute
metadata into the output `Xunit.TheoryDataRow`, and builds consistent row\-failure
[CompositionException](../Compono/Compono.CompositionException.md 'Compono\.CompositionException')s\.

### Remarks
This type never composes \- composition stays in the typed JIT/generated call sites
\(ADR\-0070\)\. `COMPONO_XUNITV3_AOT` selects the AOT namespace and makes the generator\-facing
surface [public](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/public 'https://docs\.microsoft\.com/en\-us/dotnet/csharp/language\-reference/keywords/public') \(hidden from IntelliSense with
`EditorBrowsableState.Never`\), per ADR\-0058; on the JIT package the same members are
[internal](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/internal 'https://docs\.microsoft\.com/en\-us/dotnet/csharp/language\-reference/keywords/internal')\.
