# Security Policy

## Supported Versions

Compono is in public preview (`0.x`). Only the latest published `0.x`
version of each package (`Compono`, `Compono.XunitV3`, `Compono.NSubstitute`,
`Compono.Bogus`) receives security fixes — there is no long-term-support
line yet.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for a security
vulnerability. Instead, use GitHub's private reporting flow:

1. Go to the [Security tab](https://github.com/LayeredCraft/compono/security)
   of this repository.
2. Click **"Report a vulnerability"** to open a private advisory.

This lets maintainers assess and fix the issue before it's publicly
disclosed. We'll acknowledge your report and follow up with next steps as
soon as we can.

For anything that isn't a vulnerability report (a bug, a question, a
feature idea), use the regular
[issue templates](https://github.com/LayeredCraft/compono/issues/new/choose)
instead.
