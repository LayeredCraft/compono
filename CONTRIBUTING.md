# Contributing to Compono

Thanks for your interest in contributing. Build/test instructions, coding
standards, PR conventions, and "good first issue" candidates all live on
the docs site:

**[Contributing guide →](https://layeredcraft.github.io/compono/contributing/)**
(or `docs/contributing.md` in this repo)

Before opening a PR, also read [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).
To report a security vulnerability, see [`SECURITY.md`](SECURITY.md)
instead of opening a public issue.
